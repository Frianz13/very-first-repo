## Issues Encountered & How I Solved Them

### Cursor IDE — No Extensions Tab
After installing Cursor (Current version : 3.4.20), I could not find the Extensions tab anywhere in the UI. I tried:
- All suggested keyboard shortcuts (Ctrl+Shift+X)
- View menu options
- Right-clicking the Activity Bar
- Asking multiple AI assistants. All gave the same standard answers that didn't work
- Consulted a professional mentor. Same result, could not find the Extensions tab

**Solution:** After exhausting all options, I made the decision to switch to **VS Code**, which has full extension support. I successfully installed both Claude Code and Codex there. I documented this issue transparently rather than hiding it.
